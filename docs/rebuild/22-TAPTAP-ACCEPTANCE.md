# 超好玩海龟汤：TapTap 真机验收步骤

## 当前 H5 首轮验收（2026-11-14）

开发草稿 `1059905`，小游戏标识 `tapmcowiubozfhhvw5`。当前调试包 `480319` 已上传并绑定，二维码为 `apps/taptap/artifacts/h5-test-qr-480319.png`。

1. Android 手机开启 USB 调试并允许本电脑，`adb devices -l` 应显示 `device`。
2. 在 TapTap 中登录有该小游戏测试权限的账号，使用当前 H5 自测二维码进入。
3. 打开日志面板核对来源 `https://ma-h5-al.tapimg.com`；该来源已在生产放行，题库请求应显示 200 和服务端 requestId。
4. 从首页进入题库，检查筛选与分页，选择一题进入单人。
5. 输入问题并发送，检查 AI 返回；切到还原真相，提交一次还原；查看提示与汤底；换题再进入。
6. 检查长题面、长对话、键盘遮挡、发送按钮，以及返回、切后台和关闭重进后的草稿恢复。
7. 开启飞行模式发送一次，检查失败反馈和输入保留；恢复网络后重试。
8. 导出诊断日志，结合服务端 requestId 定位实际故障，采集真实 TapTap 截图与操作记录。

浏览器自动检查使用 `apps/web/e2e/taptap-h5.spec.ts`，需填写 `TAPTAP_H5_URL` 与对照网页的 `TAPTAP_WEB_URL`。本地开发预览使用真实 API 代理，正式包的实际跨域请求和手机宿主仍需单独验收。
