# 超好玩海龟汤：TapTap 真机验收步骤

准备日期：2026-11-10。真机结果尚未填写。

这份清单用于实际安装 TapTap 的手机。代码检查与接口检查的结果在 [开发记录](22-TAPTAP.md)。

## 开始前

由开发侧准备以下条件，准备好后再约手机测试：

- [ ] 测试服务器已更新 API、官网 `/device` 页面和 `0018_device_authorization` 数据库迁移。
- [ ] 服务器已配置小游戏编号与密钥，登录接口可用。
- [ ] 手机登录的开发者 / 测试者账号已有此小游戏的调试权限。
- [ ] 电脑与手机在同一 Wi-Fi，已为当前电脑地址生成新的调试二维码。
- [ ] 手机扫码后可下载当前归档；二维码对应的下载服务保持运行。
- [ ] 双人项目准备两台手机、两个不同账号。把它们分别记作 A（房主）和 B（玩家）。

当前正式服务器尚未部署本轮新增登录接口。分享模板已创建、后台显示已审核，编号已进入代码包；用户已于 2026-11-10 确认开发者协议，后台弹窗已消失。Dirichlet 已登录，稷策游戏账户 `529328` 的资质资料已提交并显示“认证审核中”。TapTap 最新 UI 测试包已上传，开发版本 `0.1.2` / 包体 ID `460919` 已创建并绑定 `main` 主包槽位，Android 发布状态已读回为「开放试玩」，官方自测二维码已生成；Dirichlet 关联列表仍显示无匹配。开放试玩后平台要求真实实机录屏和至少 3 张截图，待扫码运行后采集。
