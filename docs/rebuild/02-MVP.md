# MVP（首发可用产品）与验收计划

## 1. 首发边界

浏览器覆盖手机和桌面；主要语言为中文，保留英文内容与翻译扩展结构。使用国内自有服务器。单人永久免费无限、记录本地；多人未赞助账号累计可开 10 个房间，6 元/月或 20 元永久赞助可不限次数开房，朋友免费加入。

| 必须交付 | 延后交付 |
| --- | --- |
| 邮箱验证码与 Google 授权登录、账号停用、显式身份绑定 | 手机号和微信登录、已存在账号自助合并 |
| 1～8 人私密房间、共享问答、讨论、提示、还原、重连 | 匹配、好友、语音、观战、竞赛 |
| 单人共用题库与判题，独立本地记录；服务端不存对话 | 单人云端同步 |
| 题库版本、来源授权、人工审核、投稿与试题 | 自动生成题库、推荐算法、作者现金分成 |
| 月度/永久赞助、10 次免费开房、主动续期、补偿、真实支付与退款 | 自动续费、优惠券、次数叠加包 |
| 内容、用户、房间、模型、订单、审计后台 | 通用低代码后台平台 |
| Docker Compose（容器服务编排）部署、备份、监控 | Kubernetes（集群编排）、多地区容灾 |
| 跨端 HTTP 与 WebSocket 数据契约 | 小程序及 App 客户端 |

登录方式和赞助价格已由用户确定；主动续期、自然月边界等具体规则采用文档默认方案。尚待外部条件为邮件服务、Google 应用凭据、支付商户和服务器配置。

## 2. 开发阶段与交付物

各阶段按完成条件推进，不把缺少人员和服务器信息时的工期估算当承诺。

| 阶段 | 可运行成果 | 必须通过的检查 | 依赖 |
| --- | --- | --- | --- |
| M0 外部能力验证 | 国内服务器可连接数据库、邮件、Google、Jev；明确商户申请路径 | 真实 Jev 判断、邮件与 Google 回调；锁定依赖版本 | 服务器、密钥、发信域名与 OAuth 应用 |
| M1 基础与身份 | 新目录、容器、账号、权限、题库导入、只读题库 | 数据迁移核对、权限测试、备份恢复演练 | M0 中身份通道 |
| M2 游玩核心 | 单人本地记录；一个多人房间提问、提示与还原 | 单人无服务端记录；双浏览器同步、并发顺序、断线和重启恢复 | M1、真实 Jev |
| M3 产品与内容 | 完整手机界面、创作中心、审核后台、举报 | 真实设备体验；题目改版不影响旧局；后台越权检查 | M2 |
| M4 赞助与收款 | 月度/永久授权、免费次数、订单、回调、查单、补偿、退款 | 真实 6 元/20 元订单与退款、重复回调、到期边界、账本核对 | 商户、支付场景批准 |
| M5 发布与迁移 | 正式部署、内容迁入、旧站切换、运营说明 | 目标服务器压力测试、数据核对、负责人体验确认 | M1～M4 完成 |

M4 的授权和账本逻辑可以在 M2 后开发；商户未就绪时只能完成内部测试版。负责人可体验测试赞助授权，收费入口保持关闭。测试授权与订单收入分开。

## 3. 产品验收场景

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 两人从邀请链接加入 | 登录后回到原房间；昵称、人数一致；朋友无需购买 |
| A02 | 八人同时提问 | 每人一个任务，序号唯一，回答紧贴对应问题，无重复判定落库 |
| A03 | 多设备重复点击发送 | 同一个请求编号只产生一个任务；不同内容复用编号返回冲突 |
| A04 | 网络在服务端受理后断开 | 重连补到同一个任务和结果，不重新消费或重复发问 |
| A05 | 提示与结束竞争 | 所有人得到相同终态；结束后不再解锁或接受判题 |
| A06 | 成功还原时仍有排队任务 | 只结算一次，未完成任务取消，汤底对本局有权成员一致可见 |
| A07 | 进行中更新题目 | 本局继续使用旧版本；下一局使用已发布新版本 |
| A08 | 房主离线、多设备切换 | 任一设备在线则仍在线；满足条件才转让；付费者不变化 |
| A09 | 用户被踢或封禁 | 后续写入和历史读取被拒绝；实时订阅终止；不能复用旧连接 |
| A10 | 后端受理后立即重启 | 已受理任务和记录仍在；恢复任务不造成多次落库或扣额度 |
| A11 | Jev 故障 | 显示真实错误状态；排队有上限；允许取消；达到条件时终止和补偿 |
| A12 | 手机键盘、弱网、长记录 | 输入和发送可见，草稿保留，回看不被新消息打断 |
| A13 | 作者提交、退回、修改、发布 | 保留版本和审核理由；未发布内容无法被普通用户读取 |
| A14 | 浏览器查看请求、静态包、实时事件 | 未公布前找不到汤底、未解锁提示、Jev 密钥或创作者私有内容 |
| A15 | 赞助支付回调重复或延迟 | 一个订单只生成一项授权；页面以服务端查单结果显示成功 |
| A16 | 免费次数剩 1，两个开房请求并发 | 只允许一个房间预留；无负余额；失败请求不消耗 |
| A17 | 月度赞助到期时已有房间 | 已创建房间可继续和换题；新房重新检查赞助或免费次数 |
| A18 | 提前续期、断档续期、永久购买 | 提前续期接原到期日；断档从当前生效；永久无截止时间 |
| A19 | 退款申请与开房竞争 | 授权冻结后不再用于新开房；退款只撤销对应订单授权 |
| A20 | 平台故障补偿重复执行 | 首局未正常结束便因故障关闭房间时，整房最多退一次；归创建者 |
| A21 | 旧邀请失效、越权查询订单 | 服务端拒绝；错误不透露其他账号信息 |
| A22 | 备份恢复 | 在空实例恢复赞助授权、账本、题库和房间；抽样核对可读且一致 |
| A23 | 未登录无限单人游玩 | 无付费与账号要求；不创建服务端用户、房间、对话记录 |
| A24 | 刷新、关页、清理单人记录 | 正常刷新能从浏览器恢复；用户可本地导出和清空；不上传 |
| A25 | 登录账号再进行单人游玩 | 单人请求不携带会话，不关联账号；免费开房余量不变 |
| A26 | 查数据库、日志、错误上报和任务队列 | 无单人问题、回答、身份或逐次追踪；仅匿名聚合统计 |
| A27 | 同一免费房间连续换题 | 整个房间只计一次，关闭再创建才使用下一次 |
| A28 | 单人主动看答案与多人进行中 | 单人按自身规则揭晓；多人房间状态不被修改，旧局任务不串局 |
| A29 | 赞助/未赞助大量正常判题 | 无累计问题额度；技术排队可恢复，不出现到数收费提示 |
| A30 | 邮箱与 Google 为同一人 | 显式验证绑定后共用账号、赞助和记录，无自动冒领或合并 |

并发和故障测试采用真实 PostgreSQL、实际网络连接和真实服务进程。Jev 真实调用只跑必要规模的评测集；同步压力测试可通过真实讨论/订阅事件压测，并单独记录模型限流边界。故障通过断网、阻断真实出站或终止进程制造，不以伪造服务响应通过验收。

## 4. 质量目标和容量假设

以下是待实测目标，未在当前服务器验证。首轮容量测试基线为 50 个房间、每房 8 人、400 条长连接；最终上线容量由目标硬件与 Jev 实际配额共同决定。

| 项目 | 首发目标 | 测量方式 |
| --- | --- | --- |
| 接受普通命令 | 第 95 百分位 ≤500ms，不含外网模型调用 | 服务端受理耗时 |
| 已提交事件同步 | 第 95 百分位 ≤1s | 同一测试网络多个客户端收到时间 |
| 重连恢复 | 1,000 条以内当前局事件，第 95 百分位 ≤3s | 网络恢复到交互恢复 |
| 模型任务 | 单次尝试超时 20s，总执行期限 45s | 独立记录排队、请求和总耗时 |
| 队列等待 | 超过 60s 未开始则失败并释放位置 | 数据库截止时间 |
| 付费一致性 | 重放、并发和恢复测试中零重复发放、零负余额 | 数据库约束与账本复核 |
| 运行可用性 | 月度 99.5% 作为初始运营目标 | 从外部监测用户关键路径 |
| 恢复目标 | 数据恢复点 ≤15min，恢复服务 ≤2h | 备份与恢复演练 |

Jev 首轮并发预算共 8 个真实请求，单人/API 进程 2 个、多人及审核任务进程 6 个，最终按供应商配额与压测容量确定。预计模型调用速率约为“活跃房间数 × 每房每分钟提交次数 + 单人总提交次数”；同时在执行的请求约为“每秒调用数 × 平均耗时”。扩大进程数量时同步调整总预算，避免每个进程各自使用全额。

单台服务器发生故障会影响全站；要达到恢复目标，备份须离机存放，并准备能恢复到备用主机的操作流程。首发备份包含 PostgreSQL 连续归档，不能仅依赖每天一次快照。

## 5. 商业上线检查

- [ ] 国内目标服务器、域名、HTTPS 和适用的备案/经营要求完成核实；责任人为产品负责人，按实际产品形态确认。
- [ ] 登录邮件或授权通道在目标用户常用网络、邮箱和设备实测成功。
- [ ] Jev 从目标服务器可达；有真实准确性、延迟、错误率与单局成本记录。
- [ ] 正式题库的首批内容通过质量与商业授权审核，建议至少 20 道不同难度题。
- [ ] 6 元/月、20 元永久、免费 10 个房间、单人无限、续期与退款条款准确展示。
- [ ] 支付商户、所需网页支付场景已开通；支付、回调、查单、退款全流程通过。
- [ ] A01～A30 通过，目标设备体验由负责人确认。
- [ ] 发布版本、迁移清单、备份位置、回退方式、报警接收人有记录。

## 6. 交付给下一位开发模型

每阶段报告只需说明：已完成的用户行为、涉及文件、验证证据、待处理问题。不得仅凭类型检查通过就声称支付、模型或多人同步已可用。文档中的测试复选框当前全部代表待完成工作。
