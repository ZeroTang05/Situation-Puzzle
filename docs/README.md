# docs/

这个目录放截图与外宣素材，方便开源推广使用。

## 宣传视频素材

`video-assets/` 收着宣传视频的截图、架构图和口播稿：13 张素材图按镜号编号，`口播稿.md` 里有分镜表、游玩录屏拍摄清单和每个数字的出处。架构图用 `scripts/render-video-diagrams.mjs` 渲染（mermaid 源码在脚本里，改完重跑即可）。
